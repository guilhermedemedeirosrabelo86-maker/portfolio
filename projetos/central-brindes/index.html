Central Brindes

Sistema web de estoque e envios que criei, por iniciativa própria, para a equipe de Marketing da empresa onde trabalho.

Abrir a demo

A demo usa dados fictícios e roda inteira no seu navegador. O código é privado, porque o sistema é usado pela empresa.

  1. Problema

    O estoque de brindes era controlado no olho, e o sistema geral da empresa vivia com dados errados e desatualizados.

  2. Solução

    Criei por iniciativa própria um sistema web completo de estoque e envios pelo Correio para representantes.

  3. Resultado

    A equipe de Marketing usa o sistema no dia a dia.

Destaques técnicos

Feito sozinho, com HTML, CSS e JavaScript puros e serviços gratuitos.

  • Estoque que nunca desencontra

    O saldo não é um número digitado: é calculado a partir do histórico (entradas + ajustes − saídas − envios). Mostra o que está reservado e o que está disponível, e cancelar um envio devolve os itens sozinho.

  • Envios com etapas e nota fiscal

    Cada envio passa por pendente → separado → entregue, com rastreio e fotos da caixa. Basta arrastar o XML ou o PDF da nota fiscal para criar o envio já com os itens ligados ao estoque.

  • Página pública de acompanhamento

    O representante abre um link próprio, vê o andamento do envio e confirma o recebimento.

  • Tarefas, conversas e notificações

    A equipe troca pedidos e tarefas dentro do sistema e recebe notificações push no celular.

  • Rotinas automáticas

    Nos dias úteis, resumos às 8h e às 14h, lembrete para chamar o Correio às 11h30, alerta de estoque baixo e backup semanal automático.

  • Login e permissões

    Acesso por usuário e senha, papéis de administrador e equipe, e regras de segurança no banco que impedem alterar o que não é seu.

  • Consultas SQL no navegador

    Administradores consultam os dados com SQL (SQLite rodando no próprio navegador) e exportam um banco para Excel ou Power BI.

  • Deploy automático

    Cada push no GitHub publica a nova versão sozinho no Cloudflare.

Stack

  • HTML
  • CSS
  • JavaScript
  • Firebase Authentication
  • Cloud Firestore
  • Firebase Cloud Messaging
  • Cloudflare Workers
  • SQLite (no navegador)
